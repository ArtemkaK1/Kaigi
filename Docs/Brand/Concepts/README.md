# Concept history

Built-in Imagegen was used for whole-icon exploration with the owner's supplied PDF as the identity anchor. A1 was flat, A2 introduced depth and #F5F5F5, A3 refined the cap and straight flanks, and A4 explored more gloss. The owner selected **A3**, rejected A4's gloss and requested clean vector reconstruction. Production uses deliberate SVG arcs/lines and a native Icon Composer document, not these raster pixels. Production approval and SHA-256 are in Tools/AppIcon/Kaigi/design-approval.yaml.
